# 🥾 Учёт походов — C

## 📌 Описание проекта

Учебная программа на языке C для учёта туристических походов.

Программа позволяет вводить информацию о трёх походах, сохранять полученные данные в текстовый файл `hikes.txt` и выполнять отбор записей по заданным условиям.

Проект разработан в рамках индивидуального задания «Вариант 17. Запись "Поход"».

## ⚙️ Функциональные возможности

- Ввод информации о трёх походах.
- Хранение данных с помощью структуры `Hike`.
- Ввод названия маршрута, начального и конечного пунктов.
- Указание дат начала и окончания похода.
- Ввод протяжённости маршрута в километрах.
- Вычисление продолжительности похода в днях.
- Учёт високосных годов при расчёте дат.
- Сохранение всех записей в текстовый файл `hikes.txt`.
- Отбор походов по заданным критериям:
  - продолжительность более одного дня;
  - протяжённость не менее заданного пользователем значения.
- Вывод найденных походов и их количества.

## 📂 Структура записи

Для хранения информации используется структура `Hike`.

| Поле | Тип данных | Описание |
|---|---|---|
| `routeName` | `char[100]` | Название маршрута |
| `startPoint` | `char[100]` | Начальный пункт |
| `endPoint` | `char[100]` | Конечный пункт |
| `startDay` | `int` | День начала |
| `startMonth` | `int` | Месяц начала |
| `startYear` | `int` | Год начала |
| `endDay` | `int` | День окончания |
| `endMonth` | `int` | Месяц окончания |
| `endYear` | `int` | Год окончания |
| `distance` | `double` | Протяжённость в километрах |

## 📝 Формат ввода данных

Названия маршрутов и пунктов необходимо вводить без пробелов. Вместо пробелов можно использовать символ `_`.

Пример:

```text
Лесной_маршрут
Лесная_станция
Озеро_Синее
```

Даты вводятся в формате:

```text
ДД ММ ГГГГ
```

Например:

```text
01 06 2026
```

Протяжённость вводится числом с дробной частью при необходимости.

## 💾 Работа с файлом

После ввода трёх походов программа автоматически создаёт текстовый файл `hikes.txt` и записывает в него все данные.

Каждая запись располагается на отдельной строке.

Пример содержимого файла:

```text
Лесной_маршрут Лесная_станция Озеро_Синее 1 6 2026 4 6 2026 25.50
Горный_маршрут Город_Альфа Гора_Высокая 5 7 2026 8 7 2026 40.00
Озерный_маршрут Поселок_Берег Деревня_Лесная 10 8 2026 13 8 2026 55.00
```

Файл открывается в режиме записи (`"w"`). При повторном запуске программы его предыдущее содержимое перезаписывается.

## 🔍 Пример работы программы

Пусть пользователь ввёл три похода:

| Маршрут | Продолжительность | Протяжённость |
|---|---:|---:|
| Лесной | 3 дня | 25.50 км |
| Горный | 3 дня | 40.00 км |
| Озерный | 3 дня | 55.00 км |

Минимальная протяжённость, заданная пользователем: **30 км**.

Результат отбора:

- Горный маршрут — подходит.
- Озерный маршрут — подходит.
- Лесной маршрут — не подходит, так как его протяжённость меньше 30 км.

Всего найдено походов: **2**.
